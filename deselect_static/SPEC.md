# Deselect Static — 詳細仕様

## 概要
- バージョン: 0.1.0 / 対応Maya: 2024+
- カテゴリ: Animation
- 表示場所: シェルフボタン `DeselStat`（左クリックで起動）
- 選択オブジェクトのうち、キーの値が変化しないものの選択を外し、値が動いている
  オブジェクトだけを選択に残す。 Graph Editor でキーが選択されていればその
  キーだけで判定する。

## アーキテクチャ

```
../install.py       リポジトリ直下のハブ。 全ツールをまとめて配る（触らない）
deselect_static/
  __init__.py       __version__（版数の唯一の情報源）/ SHELF_LABEL / show()
  core.py           Maya 非依存の純ロジック ← 自宅でテストできるのはここだけ
  ui.py             cmds による UI。 値を集めて core に渡すだけ
  dev_tools.py      バージョン表示と「GitHub から更新」（全ツール共通・触らない）
```

### 設計判断

- **`core` と `ui` を分ける。** 開発機に Maya が無いため、`cmds` を呼ぶコードは
  実機に持っていくまで一度も実行されない。 判定・計算・命名規則を `core` に
  寄せた分だけ手元で検証できる範囲が広がる。
- **更新は SHA 固定 URL から取る。** `raw.githubusercontent.com` の CDN は
  クエリ文字列を無視してパスだけでキャッシュするので、ブランチ名の URL では
  更新が届かないことがある（`docs/MAYA_HOT_UPDATE_PATTERNS.md` §1-7）。
- **更新は 3 段に分ける。** ボタンのコールバックの中で自分の親ウィンドウを
  消すと、その後に開いたウィンドウが見えなくなる。 `evalDeferred` で段を
  分けて避ける（同 §1-9）。
- **ダウンロードは全ファイルを揃えてから書く。** 途中で失敗しても、新旧が
  混ざったパッケージを実機に残さないため（同 §1-4 の発展）。
- **ウィンドウ名は `<NAMESPACE>_<モジュール名>Win` 固定。** ハブがこの規則で
  古いウィンドウを閉じる。 テストで規則違反を検出する。
- **配布リストを持たない。** ハブが tree API で `<名前>/<名前>/` を列挙するので、
  モジュールを足しても登録作業が無い（同 §1-10 / §2-6）。

## 機能詳細

### 1. インストール（リポジトリ直下の `install.py`）
- Maya のビューポートへドラッグ&ドロップ、または Script Editor から `exec`
- `userScriptDir` に**全ツール**のパッケージを配置し、シェルフボタンを貼る
- 完了ダイアログにツールごとの `previous → current` を出す

### 2. 更新（`dev_tools.update_from_github`）
- ツール UI 下端の「GitHub から更新」ボタン
- シェルフボタンの右クリック > Update All Tools（パッケージが壊れていても動く）
- どちらも**入っているツールを全部まとめて更新する**

### 3. Deselect Static（`ui.deselect_static` / `core.split_by_change`）
- 対象は `cmds.ls(selection=True, long=True)` の選択オブジェクト
- 各オブジェクトのアニメカーブは `cmds.keyframe(obj, q=True, name=True)` で取る
- **判定に使うキー**（`core.choose_source`）
  - Graph Editor / Dope Sheet でキーが選択されていて、選択オブジェクトのカーブと
    重なる → **選択キーだけ**で判定する。 キーが 1 つも選択されていない
    オブジェクトは「変化なし」として外す
  - キー選択が無い、または選択オブジェクトのカーブと 1 本も重ならない →
    **全キー**で判定する（関係ないキー選択で全部外れるのを防ぐ安全側）
- **変化の判定**（`core.has_change`）: カーブごとに キー値の `最大 - 最小 > Tolerance`。
  1 本でも満たせば「変化あり」。 キー 0〜1 個のカーブは変化なし
  - 隣同士の差ではなく全体の幅を見る（ゆっくり漂うカーブを取りこぼさない）
  - Tolerance は UI で指定、既定 `1e-4`。 optionVar `ntk_deselect_static_tolerance`
  - 値は `keyframe -q -valueChange` の UI 単位（回転は度）。 単位をまたいで同じ値を使う
- 選択の変更は 1 回の undo にまとめる。 選択キーで判定したときは、残した
  オブジェクトのキー選択を復元する（復元に失敗しても警告だけで主機能は止めない）
- 結果は Script Editor と inViewMessage に出す
- `deselect_static(tolerance=None)` は UI 無しでも呼べる（ホットキー用）

### 制約
- 判定は**キーの値だけ**。 同じ値のキー間でタンジェントにより膨らむ動きは見ない
- 選択したトランスフォームのカーブだけを見る（シェイプ・接続先ノードのアニメは見ない）
- アニメーションレイヤー使用時に `keyframe -q -name` がどのレイヤーのカーブを返すかは
  実機未確認
