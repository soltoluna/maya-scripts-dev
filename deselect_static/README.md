# Deselect Static

## 概要
- バージョン: 0.1.0 / 対応Maya: 2024+
- 選択したオブジェクトのうち、キーの値が変化しない（止まっている）ものの選択を
  外し、動いているオブジェクトだけを選択に残す。

## インストール

1. GitHub の**リポジトリ直下**の `install.py` を開き、**Raw** から保存する
2. 保存した `install.py` を **Maya のビューポートにドラッグ&ドロップ**する
3. 完了ダイアログが出て、シェルフに `DeselStat` ボタンが追加される

Maya の再起動は不要。 **この `install.py` はリポジトリの全ツール共通**で、
1 回のドラッグで入っているツールが全部インストール／更新される。

## 使い方

1. 判定したいオブジェクトを選択する
2. （任意）Graph Editor / Dope Sheet で、判定に使いたい範囲のキーを選択する
3. シェルフボタン `DeselStat` を**左クリック**してウィンドウを開き、
   **Deselect Static** を押す

- **キーが選択されていれば、選択したキーだけ**で判定する。 選択キーの値が全部同じ
  オブジェクトと、キーが 1 つも選択されていないオブジェクトは選択から外れる
- キーが選択されていなければ、各オブジェクトの**全キー**で判定する
- **Tolerance**: キー値の 最大 - 最小 がこれ以下なら「変化なし」とみなす（既定 0.0001）。
  値は次回も残る
- 結果（残した数 / 外した数）はビューポート上部と Script Editor に出る。
  外したオブジェクト名は Script Editor に並ぶ
- Ctrl+Z で選択を元に戻せる

UI を開かずに実行したい場合（ホットキーなど）:

```python
import deselect_static
deselect_static.ui.deselect_static()
```

## 更新

**ドラッグ&ドロップし直しても更新されない**（Maya は同じファイルの 2 回目の
ドロップを無視する）。 次のどちらかで更新する。

- ツールウィンドウ下端の **「GitHub から更新」** ボタン
- シェルフボタンを**右クリック** > **Update All Tools from GitHub**

どちらも Maya の再起動は不要。 更新後はウィンドウが自動で開き直り、下端の
バージョン表示が新しい番号に変わる。 **変わっていなければ更新は届いていない。**

## 制約・既知の問題

- 判定するのは**キーの値だけ**。 同じ値のキーの間でタンジェントによって
  膨らむ動きは「変化なし」になる
- 選択したノード自身のアニメーションだけを見る（シェイプなど別ノードのキーは見ない）
- 回転（度）も移動も同じ Tolerance で判定する

- 更新には GitHub への HTTPS 接続が必要。 社内プロキシやセキュリティソフトで
  塞がれている場合は Script Editor に `URLError` が出る。 その場合は
  **ルートの README「GitHub に接続できないとき」**のオフライン手順で入れられる
- Maya 2024 / 2025 の両方で動くよう、Python 3.10 の構文と `maya.cmds` だけで
  書いてある（PySide は 2024=PySide2 / 2025=PySide6 で互換が無いため使っていない）
