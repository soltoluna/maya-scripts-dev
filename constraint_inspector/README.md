# Constraint Inspector

## 概要
- バージョン: 0.1.0 / 対応Maya: 2024+（2024 = PySide2 / 2025 = PySide6）
- シーン（または指定したノード以下）のコンストレインを一覧し、種類・名前で
  絞り込んで、ドリブン（コンストレイン先）・ドライバー（コンストレイン元）・
  コンストレインノードを選択できる。

## インストール

1. GitHub の**リポジトリ直下**の `install.py` を開き、**Raw** から保存する
2. 保存した `install.py` を **Maya のビューポートにドラッグ&ドロップ**する
3. 完了ダイアログが出て、シェルフに Constraint Inspector のアイコンのボタン
   （ラベル `ConstInsp`）が追加される

Maya の再起動は不要。 **この `install.py` はリポジトリの全ツール共通**で、
1 回のドラッグで入っているツールが全部インストール／更新される。
既にハブを入れている人は、どれかのツールの「GitHub から更新」を押すだけで
このツールも入る。

## 使い方

1. シェルフボタンを**左クリック**してウィンドウを開く
2. **Root** にルートノード名を入れる（**選択から取得** で選択中のノードを入れられる。
   空欄ならシーン全体）→ **スキャン**
3. 一覧の行をクリックすると、そのコンストレインノードを選択する。
   ドリブン列・ドライバー列のセルをクリックするとそれぞれを選択する
4. 右の詳細パネルから、ドリブンの選択 / 追加選択、ドライバーごとの選択ができる

上部のフィルターで、ノード名・コンストレインの種類で絞り込める。

スクリプトから開く場合:

```python
import constraint_inspector
constraint_inspector.show()
```

**単体スクリプト時代と違い、`import` しただけでは開かない**（`show()` を呼ぶ）。

## 更新

**ドラッグ&ドロップし直しても更新されない**（Maya は同じファイルの 2 回目の
ドロップを無視する）。 次のどちらかで更新する。

- ウィンドウ右下（ステータスバー）の **「GitHub から更新」** ボタン
- シェルフボタンを**右クリック** > **Update All Tools from GitHub**

どちらも Maya の再起動は不要。 更新後はウィンドウが自動で開き直り、タイトルと
右下のバージョン表示が新しい番号に変わる。 **変わっていなければ更新は届いていない。**

## 制約・既知の問題

- **以前の単体版 `constraint_inspector.py` を手で置いていた場合は消す。**
  ハブと同じフォルダ（`userScriptDir`）なら新しいパッケージが優先されるが、
  別のフォルダ（`Documents\maya\scripts` など）にあると**古い単体版が読まれる
  ことがある**。 単体版を開くために自作したシェルフボタンも消す（`import` だけで
  開く前提のボタンは、新しい版では何も開かない）。 どちらが読まれているかは
  Script Editor で `import constraint_inspector; print(constraint_inspector.__file__)`
- PySide2 / PySide6 の差は `qt.py` で吸収している。 **自宅では PySide を
  import できないため、Qt の挙動は実機でしか確かめられない**
- 更新には GitHub への HTTPS 接続が必要。 塞がれている場合は
  **ルートの README「GitHub に接続できないとき」**のオフライン手順で入れられる
