# Scene TimeWarp HUD — 変更履歴

現時点の仕様と確定した設計判断は `SPEC.md` を参照。 ここではバージョンごとの
経緯・試行錯誤・不具合修正の細部を記録する。 降順（新しい順）。

## 0.1.0 — 標準セットに載せ、シェルフから切り替えられるようにした
- 単体スクリプト `scene_timewarp_hud.py` をパッケージ `scene_timewarp_hud/`
  に移し、ハブ `install.py` から配布・シェルフ登録されるようにした
  （フォルダ名も `TimewarpHUD` → `scene_timewarp_hud` に変更）
- シェルフボタン（`show()`）で HUD の表示 / 非表示を切り替え、バージョンを
  ビューポートのメッセージに出す
- scriptJob の番号と元の色をモジュール変数から `__main__` へ移した
  （更新でモジュールが読み直されても後片付けできるように）
- 表示文字列と色の判定を `core.py` に切り出した
- これ以前（単体スクリプト時代）の経緯は記録が無い
