# Tangent Fixer

## 概要
- バージョン: 0.1.0 / 対応Maya: 2024+
- Fカーブのタンジェントを、極値はフラット・中間キーは前後と滑らかにつなぎ、
  キーに無いオーバーシュートを作らない形に一括で直す。
  - Auto で起きる「山と谷の間のキーでカーブが少し歪む」を出さない
  - Spline で起きる「打っていないオーバーシュート」を出さない

## インストール

1. GitHub の**リポジトリ直下**の `install.py` を開き、**Raw** から保存する
2. 保存した `install.py` を **Maya のビューポートにドラッグ&ドロップ**する
3. 完了ダイアログが出て、シェルフに `TanFixer` ボタンが追加される

Maya の再起動は不要。 **この `install.py` はリポジトリの全ツール共通**で、
1 回のドラッグで入っているツールが全部インストール／更新される。

## 使い方

1. シェルフボタン `TanFixer` を**左クリック** — ウィンドウが開く
2. Graph Editor で直したいキーを選択する（**キーを選んでいなければ、選択
   オブジェクトの全キー**が対象）
3. `End Keys` を選ぶ
   - `Flat` — カーブの最初と最後のキーは水平（既定）
   - `Natural` — 最初と最後のキーも隣のキーへ向ける（はみ出さない範囲で）
4. **Fix Tangents** を押す。 1 回の undo で元に戻せる

直したキーのタンジェントは **Fixed**（ロック付き）になる。 Auto / Spline に
戻すと Maya の計算に戻る。

ホットキーに登録するなら:

```python
import tangent_fixer
tangent_fixer.fix()                 # ウィンドウで最後に選んだ End Keys で
tangent_fixer.fix("natural")        # 端も隣へ向ける
```

## 更新

**ドラッグ&ドロップし直しても更新されない**（Maya は同じファイルの 2 回目の
ドロップを無視する）。 次のどちらかで更新する。

- ツールウィンドウ下端の **「GitHub から更新」** ボタン
- シェルフボタンを**右クリック** > **Update All Tools from GitHub**

更新後はウィンドウが自動で開き直り、下端のバージョン表示が新しい番号に変わる。
**変わっていなければ更新は届いていない。**

## 制約・既知の問題

- 極値のキーは必ず水平になる。 わざと傾けた山（勢いを残した頂点）は残らない
- 段差（Stepped）のキーは触らない
- ウェイト付きタンジェントのカーブはウェイトを変えないので、はみ出しが残る
  ことがある（警告が出る）
- 結果がおかしいときは、カーブを選んで Script Editor で次を実行し、出力を貼ってほしい:

  ```python
  import tangent_fixer
  tangent_fixer.probe()               # 読むだけ（シーンは変わらない）
  tangent_fixer.probe(try_it=True)    # 一時ノードで試して消す
  ```
- 更新には GitHub への HTTPS 接続が必要。 繋がらない場合は
  **ルートの README「GitHub に接続できないとき」**のオフライン手順で入れられる
