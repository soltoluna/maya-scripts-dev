# Penetration Checker — 詳細仕様

## 概要
- バージョン: 0.2.0 / 対応Maya: 2024+
- カテゴリ: Animation
- 表示場所: シェルフボタン `PenetChk`（左クリックで起動。 ドロップしたときに開いていたシェルフに貼られる）
- 指定した複数のオブジェクト／グループ配下のメッシュ同士のめり込みを、現在のフレーム・
  タイムスライダーの範囲・再生しながら（ライブ）の 3 通りで調べ、めり込み区間と
  最も効いているコントローラー（無ければジョイント）をビューポートの HUD と一覧に出す。
  シーンは変更しない。

## アーキテクチャ

```
../install.py       リポジトリ直下のハブ。 全ツールをまとめて配る（触らない）
penetration_checker/
  __init__.py       __version__（版数の唯一の情報源）/ SHELF_LABEL / show() / diagnose() / set_backend()
  core.py           Maya 非依存の純ロジック ← 自宅でテストできるのはここだけ
                    ボックス・内外判定・スコア集計・コントローラー探索・
                    Checker（1 フレーム分の段取り）・scan・group_frames・HUD の文言
  scene.py          シーンを読む層（OpenMaya 2.0 + cmds）。 MeshAdapter と時間まわりの関数
  ui.py             cmds の UI。 3 つの入口・scriptJob・HUD・一覧
  dev_tools.py      バージョン表示と「GitHub から更新」（全ツール共通・触らない）
```

### データの流れ

```
            ┌ 現在のフレーム ─┐
ui ─────────┼ 範囲スキャン ───┼─→ core.Checker.check_frame() ─→ results{frame: 結果}
            └ ライブ(timeChanged)┘          │                           │
                                     scene.MeshAdapter            core.group_frames
                                     (座標・最近接点・ウェイト)       │
                                                              区間一覧 / 内訳 / HUD
```

- **3 つの入口が同じ結果表 `results` に書く。** スキャンした後に再生すると、
  ライブがオフでも `timeChanged` で結果表を引いて HUD を更新する（再生は重くならない）
- `core.Checker` はメッシュのアダプターと解決関数を受け取り、フレームごとに
  1. 全メッシュの `begin_frame()`（座標キャッシュを捨てる）とボックス
  2. ボックスが重なる組だけ候補にする
  3. 候補の両方向で「A の頂点が B の内側にあるか」（B のボックス外は問い合わせない）
  4. めり込み頂点（深い順に最大 200）のスキンウェイトを集計し、組ごとに最も効く
     インフルエンスを選ぶ → コントローラーへ解決 → 同じ対象をまとめて順位付け
- **フレームをまたいで変わらないものはキャッシュする**: スキンウェイト（頂点ごと）、
  インフルエンス → コントローラーの解決、メッシュが閉じているか。 ライブで効く

### 設計判断

- **内外判定は「最近接点 + 法線の符号」。** 頂点 p と、相手メッシュ上の最近接点 c・
  そこの外向き法線 n について `(p − c)·n < 0` なら内側。 深さは `−(p − c)·n/|n|`。
  頂点だけを見るので、頂点が外にあって辺だけが面を突き抜けるケースは拾わない。
- **最近接点は `MMeshIntersector` を既定にする（v0.2.0）。** v0.1.0 の
  `MFnMesh.getClosestPointAndNormal` は総当たりで、範囲スキャンやライブでは遅すぎる。
  Intersector は**単位行列で作ってオブジェクト空間で問い合わせ**、点は行列・法線は
  逆行列の転置でワールドへ戻す。 「行列を渡したときに戻り値がどの空間か」を推測しない
  ためで、非一様スケールでも法線の向きが正しい。 旧方式は `set_backend("fnmesh")` で
  戻せる（optionVar `ntk_penetration_checker_backend` に保存）。 `diagnose()` が両者を並べる。
- **開いたメッシュは既定で「めり込まれる側」にしない。** 1 枚布の裏側を内側と
  みなすと、服の下の体がすべて「服の中」と判定される。 布が体に刺さっている向きは調べる。
- **座標は内部単位（cm）で統一する。** ボックスも点から作る（`exactWorldBoundingBox` は
  UI 単位）。 許容値の入力と深さの表示だけ `MDistance` で変換する。
- **スコアは `Σ weight × (depth + ε)`。** 深く刺さっている頂点を強く効かせる。
  区間のまとめでは、区間内の各フレームのスコアを合計して並べる。
- **コントローラーの探索は幅優先で「入力接続 → DAG の親」。** 最初に当たったものを
  採る。 コントローラーは「`controller` タグ付き」か「NURBS カーブのシェイプを持つ
  トランスフォーム」。 ジョイントからは DAG の親を辿らない（親のコントローラーを拾うため）。
  `message` / `inverseScale` / `drawOverride` などの接続は無視する。
- **スキャンは `currentTime(update=True)` で 1 フレームずつ動かす。** 描画を止める
  （`refresh(suspend=True)`）と速くなるが、評価マネージャーの下で座標が更新される
  保証が取れていないので使わない。 終わったら（例外でも）元のフレームに戻す。
  スキャン中は自分の `timeChanged` を無視する（二重に調べないため）。
- **再生中は HUD だけを更新する。** 一覧の作り直しは再生が止まったとき
  （`scriptJob conditionFalse=playingBack`）にまとめて行う。
- **`timeChanged` の中では例外を上げない。** 再生中に毎フレームエラーが出続けるため。
  ライブの判定に失敗したらライブを切って 1 度だけ警告する。 HUD が作れなくても判定は止めない。
- **scriptJob はウィンドウに親子付けして、閉じたら自動で消す。** HUD はウィンドウの
  `uiDeleted` で消す。 シーンを開き直したら対象・結果をクリアする。
- **判定の条件（対象・許容値・オプション）を変えたら結果をクリアする。** 古い条件の
  結果が混ざった区間一覧は信用できないため。
- **シーンを変更しない。** 変わるのは選択・時間（スキャン中のみ・元に戻す）・HUD だけ。
- **実機で想定と違ったときのために `diagnose()` を置く**（CLAUDE.md「推測で直さない」）。

## 機能詳細

### 1. 対象の指定
- 「選択を追加」で選択中のノードを登録（グループ可。 配下のメッシュ全部が対象）
- リストが空なら、調べるときに選択中のものを対象にする
- リストの行をクリックするとそのノードを選択

### 2. 調べ方
- **現在のフレーム** — 1 フレームだけ。 「自動で選択」がオンなら 1 位を選択
- **タイムスライダーの範囲をスキャン** — タイムスライダーで範囲を選んで（Shift+ドラッグ）
  いればその範囲、無ければ再生範囲を 1 フレームずつ。 Esc で中断（途中までの結果を残す）
- **ライブ（再生しながら）** — 時間が変わるたびに調べる（再生・スクラブ・キー移動）。
  再生が遅くなるので、取りこぼしたくなければ「Play every frame」で再生する

### 3. 結果
- **めり込み区間** — 連続したフレームを 1 行に。 `12-18 (7f)  hand_ctl ほか 1  max 0.83cm @15`。
  クリックで最も深いフレームへ移動し、内訳を出し、（オンなら）1 位を選択
- **内訳** — 今のフレームの対象を影響の大きい順に。 クリックで選択。
  「めり込み頂点を選択」で、その行のめり込み頂点を選択
- **HUD** — ビューポート下段中央に `Penetration: HIT hand_ctl 0.5cm (+1)` /
  `OK` / `-- (not checked)`。 スキャン後に再生すると、めり込むフレームが追える
- **結果をクリア** — 結果表を空にする

### 4. オプション（optionVar に保存）
- 許容する深さ / 開いたメッシュも内側があるものとして調べる（既定オフ）/
  非表示のメッシュを除く（既定オン。 判定の開始時点の表示で決める）/
  自動で選択（既定オン）/ HUD を表示（既定オン）
- キー: `ntk_penetration_checker_tolerance` / `_open_containers` / `_skip_hidden` /
  `_auto_select` / `_show_hud` / `_backend`

### 5. 調査関数
- `penetration_checker.diagnose()` — 選択中のノードについて、上流の接続・コントローラー
  判定・探索結果・スキン・閉じているか・評価マネージャーのモード・調べる範囲を出す。
  **メッシュを 2 つ選ぶと、最近接点を 2 方式（intersector / fnmesh）で並べる**
- `penetration_checker.set_backend("fnmesh" | "intersector")`

## 実装状況

### v0.2.0
- 時間軸に対応（範囲スキャン・ライブ・HUD・区間一覧）。 判定の段取りを `core.Checker` に
  移し、偽のメッシュ（動く球）でスキャンとまとめまで自宅でテストした。
  最近接点を `MMeshIntersector` に変更。 **実機未確認**（Maya 2024 / 2025 とも）。
- 実機で確かめること:
  1. めり込んでいる 2 メッシュを選んで `diagnose()` — intersector と fnmesh の
     最近接点・depth が一致するか（**一致しなければ `set_backend("fnmesh")` で回避して報告**）
  2. 球 2 つを動かすアニメーションで範囲スキャン → 区間が正しい / 元のフレームに戻る / Esc で止まる
  3. タイムスライダーで範囲を選んだときにその範囲だけ調べる
  4. スキャン後に再生 → HUD が HIT / OK に切り替わる
  5. ライブをオンにして再生 → HUD が追従する、再生が止まると一覧が更新される、
     どれくらい遅くなるか（評価マネージャーが Parallel のときに座標が正しいか）
  6. ウィンドウを閉じると HUD が消える / シーンを開き直すと結果が消える
  7. スキンされたキャラで手のコントローラーが選ばれる（v0.1.0 からの持ち越し）
- 未対応（候補）: 辺の貫通、1 メッシュ内の自己交差、タイムスライダー上の印（ブックマーク）

### v0.1.0
- 初版。 現在のフレームだけを調べる。 実機未確認のまま v0.2.0 で作り直した。
