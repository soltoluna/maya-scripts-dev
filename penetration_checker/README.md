# Penetration Checker

## 概要
- バージョン: 0.2.0 / 対応Maya: 2024+
- 指定した複数のオブジェクト／グループ配下のメッシュ同士のめり込みを、現在のフレーム・
  タイムスライダーの範囲・再生しながら（ライブ）の 3 通りで調べ、めり込み区間と
  最も効いているコントローラー（無ければジョイント）をビューポートの HUD と一覧に出す。
  シーンは変更しない。

## インストール

1. GitHub の**リポジトリ直下**の `install.py` を開き、**Raw** から保存する
2. **ボタンを置きたいシェルフのタブを開いた状態で**、保存した `install.py` を
   Maya のビューポートにドラッグ&ドロップする
3. 完了ダイアログが出て、開いていたシェルフに `PenetChk` ボタンが追加される

Maya の再起動は不要。 **この `install.py` はリポジトリの全ツール共通**で、
1 回のドラッグで入っているツールが全部インストール／更新される。

ボタンは後から好きなシェルフへ中ボタンドラッグで移してよい。 起動するだけなら
Script Editor（Python）で次でもよい:

```python
import penetration_checker; penetration_checker.show()
```

## 使い方

1. 調べたいオブジェクトかグループを選び、**選択を追加**（キャラ全体のグループを
   入れれば配下のメッシュ同士を総当たりで調べる）。 リストが空なら選択中のものを調べる
2. 調べ方を選ぶ
   - **タイムスライダーの範囲をスキャン** — 再生範囲（タイムスライダーで Shift+ドラッグして
     範囲を選んでいればその範囲）を 1 フレームずつ調べる。 Esc で中断。 終わると元の
     フレームに戻る
   - **ライブ（再生しながら）** をオン — 再生・スクラブするたびにその場で調べる。
     再生は遅くなる。 全フレームを見たいときは再生設定を「Play every frame」にする
   - **現在のフレーム** — 今のフレームだけ
3. **めり込み区間** に `12-18 (7f)  hand_ctl ほか 1  max 0.83cm @15` のように並ぶ。
   クリックすると一番深いフレーム（@15）へ移動し、そこで一番効いているコントローラーが
   選択される。 そのまま動かして直せる
4. **内訳** には今のフレームの対象が影響の大きい順に並ぶ。 クリックで選択、
   **めり込み頂点を選択** で刺さっている頂点を選択
   - `[CTRL]` コントローラー / `[JNT]` コントローラーが見つからずジョイント /
     `[OBJ]` スキンの無いメッシュ自身
5. **ビューの HUD**（ビューポート下段中央）に今のフレームの結果が出る。
   スキャンした後に再生すると、`Penetration: HIT hand_ctl 0.5cm` / `OK` が切り替わり、
   どこでめり込むかを再生しながら追える（スキャン済みのフレームは再生が重くならない）

対象やオプションを変えると、それまでの結果はクリアされる（条件の違う結果を混ぜないため）。
アニメーションを直したら、もう一度スキャンするかライブで確かめる。

オプション:

- **許容する深さ** — これ以下のめり込みは無視（シーンの単位）
- **開いたメッシュも「内側」があるものとして調べる** — 既定オフ。 1 枚布のような
  開いたメッシュは「めり込まれる側」としては調べない（裏側を内側とみなすと、
  服の下の体が全部「めり込み」になるため）。 布が体を突き抜けている向きは調べる
- **非表示のメッシュを除く** — 既定オン（調べ始めた時点の表示で決まる）
- **最も影響の大きいコントローラーを自動で選択** — 既定オン
- **ビューに HUD を表示** — 既定オン。 ウィンドウを閉じると消える

## 制約・既知の問題

- **頂点の内外だけを見る。** 頂点が外にあって辺だけが突き抜けている箇所は出ない
- めり込まれる側は**閉じたメッシュ**が前提（上のオプション参照）
- ライブは重いシーンで再生が遅くなる。 普段はスキャン → 再生で確認し、直している
  最中だけライブにするのがおすすめ
- コントローラーの判定は「`controller` タグ付き」か「NURBS カーブのシェイプを持つ
  トランスフォーム」。 リグによっては期待と違うものが選ばれる
- 結果がおかしいときは、めり込んでいるメッシュ 2 つ（またはジョイント）を選んで
  次を実行し、出力を開発者に渡す:

  ```python
  import penetration_checker; penetration_checker.diagnose()
  ```

  明らかに見落とす・誤検出するときは、遅いが確実な方式に切り替えられる
  （`"intersector"` で元に戻る）:

  ```python
  import penetration_checker; penetration_checker.set_backend("fnmesh")
  ```

- 更新には GitHub への HTTPS 接続が必要。 塞がれている場合は
  **ルートの README「GitHub に接続できないとき」**のオフライン手順で入れられる

## 更新

**ドラッグ&ドロップし直しても更新されない**（Maya は同じファイルの 2 回目の
ドロップを無視する）。 次のどちらかで更新する。

- ツールウィンドウ下端の **「GitHub から更新」** ボタン
- シェルフボタンを**右クリック** > **Update All Tools from GitHub**

どちらも Maya の再起動は不要。 更新後はウィンドウが自動で開き直り、下端の
バージョン表示が新しい番号に変わる。 **変わっていなければ更新は届いていない。**

- 変更履歴: `CHANGELOG.md`
- テスト（Maya 不要）: `cd tests && python -m unittest discover -v`
