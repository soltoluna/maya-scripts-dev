# Penetration Checker — 変更履歴

現時点の仕様と確定した設計判断は `SPEC.md` を参照。 ここではバージョンごとの
経緯・試行錯誤・不具合修正の細部を記録する。 降順（新しい順）。

## 0.2.0 — 時間軸で調べる（範囲スキャン・ライブ・HUD）
- 要望: 「現在のフレームだけでなくタイムスライダーの範囲を確認したい。 再生しながら
  確認できると良い」。 v0.1.0 は実機未確認だったので、互換を気にせず構造から変えた。
- **判定の段取りを `core.Checker` に移した。** v0.1.0 は `scene.check()` が 1 回で
  全部やっていたが、フレームごとに繰り返すには「フレームをまたいで変わらないもの
  （スキンウェイト・コントローラーの解決・閉じているか）」と「毎フレーム読むもの
  （座標・最近接点）」を分ける必要がある。 `scene` はアダプター（`MeshAdapter`）を
  渡すだけになり、スキャンと区間のまとめまで偽のメッシュ（動く球）で自宅テストできる
- 3 つの入口（現在のフレーム / 範囲スキャン / ライブ）が同じ結果表に書く形にした。
  スキャン後の再生は結果表を引くだけなので、重くならずに HUD でめり込みを追える
- **最近接点を `MMeshIntersector` に変更。** `MFnMesh.getClosestPointAndNormal` は
  総当たりで、範囲スキャンには遅すぎる。 戻り値の空間を推測しないよう、単位行列で
  作ってオブジェクト空間で問い合わせる。 実機未確認なので旧方式に戻す
  `set_backend("fnmesh")` と、両者を並べる `diagnose()` を付けた
- スキャン中に描画を止める（`refresh(suspend=True)`）案は見送った。 評価マネージャー
  の下で座標が更新されるかを確かめられないため（推測で入れない）
- HUD の文言は ASCII だけにした（HUD のフォントで日本語が化ける環境に備える）
- 区間をクリックすると最深フレームへ移動して選択する。 「区間 → どのフレームを
  直すか」を 1 クリックにするため

## 0.1.0 — 初版
- 標準セット付きで新規作成し、最初の機能まで入れた（2026-11-17）。 **実機未確認。**
- 要件の確定時の判断:
  - 用途はアニメーション作業中。 めり込みを「見せる」より、**直すべきコントローラーを
    選択する**ことを表示の主役にした（コントローラーが無ければジョイント）
  - 検査範囲は指定物の全ペア総当たり。 判定は頂点の内外（最近接点 + 法線）
  - シェルフは専用のものを作らず、ハブが「ドロップ時に開いていたシェルフ」に貼る
    既存の動作のまま（各自好きなシェルフに置く運用）
- 判定・集計・コントローラー探索は `core.py` に寄せて自宅でテストした。 OpenMaya の
  戻り値（`getClosestPointAndNormal` の法線の向き、`skinPercent` の順序）と
  リグごとの接続の形は実機でしか分からないので、`diagnose()` を同梱した。
