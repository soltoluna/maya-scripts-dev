# Penetration Checker — 変更履歴

現時点の仕様と確定した設計判断は `SPEC.md` を参照。 ここではバージョンごとの
経緯・試行錯誤・不具合修正の細部を記録する。 降順（新しい順）。

## 0.1.0 — 初版
- 標準セット付きで新規作成し、最初の機能まで入れた（2026-11-17）。 **実機未確認。**
- 要件の確定時の判断:
  - 用途はアニメーション作業中。 めり込みを「見せる」より、**直すべきコントローラーを
    選択する**ことを表示の主役にした（コントローラーが無ければジョイント）
  - 検査範囲は指定物の全ペア総当たり。 判定は頂点の内外（最近接点 + 法線）
  - シェルフは専用のものを作らず、ハブが「ドロップ時に開いていたシェルフ」に貼る
    既存の動作のまま（各自好きなシェルフに置く運用）
- 判定・集計・コントローラー探索は `core.py` に寄せて自宅でテストした。 OpenMaya の
  戻り値（`getClosestPointAndNormal` の法線の向き、`skinPercent` の順序）と
  リグごとの接続の形は実機でしか分からないので、`diagnose()` を同梱した。
