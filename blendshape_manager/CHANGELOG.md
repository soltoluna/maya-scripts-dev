# BlendShape Manager — 変更履歴

現時点の仕様と確定した設計判断は `SPEC.md` を参照。 ここではバージョンごとの
経緯・試行錯誤・不具合修正の細部を記録する。 降順（新しい順）。

## 0.1.0 — 初版（実機未確認）
- 作成 / ノード選択 / ターゲット一覧（チェック + スライダー + 絞り込み）/
  追加・削除 / ウェイト一括 / リネーム（単体・一括）/ インビトウィーン /
  ミラーを実装。
- ミラーは Maya の `flipTarget` / `mirrorTarget` を使わず、blendShape の出力を
  読んで `core` で反転する方式にした。 計算を自宅でテストできることと、
  スキンなど他のデフォーマの影響を受けないことを優先した。
- 削除は `blendShapeDeleteTargetGroup`（Shape Editor と同じ）を優先し、
  失敗したら直接外す。 呼び出し形は実機未確認なので `scene.diagnose()` を
  同梱した。
