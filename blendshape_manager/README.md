# BlendShape Manager

## 概要
- バージョン: 0.1.0 / 対応Maya: 2024+
- ブレンドシェイプの作成・ターゲットの追加 / 削除・ウェイト操作・リネーム
  （一括を含む）・インビトウィーンの追加・左右反転したターゲットの作成を
  1 つのウィンドウで行う。

## インストール

1. GitHub の**リポジトリ直下**の `install.py` を開き、**Raw** から保存する
2. 保存した `install.py` を **Maya のビューポートにドラッグ&ドロップ**する
3. 完了ダイアログが出て、シェルフに `BSManager` ボタンが追加される

Maya の再起動は不要。 **この `install.py` はリポジトリの全ツール共通**で、
1 回のドラッグで入っているツールが全部インストール／更新される。

## 使い方

シェルフボタンを**左クリック**するとウィンドウが開く。

### 作る
1. ターゲットにしたいメッシュを選び、**最後にベース**を追加選択する
   （ベースだけでもよい）
2. 「作成」の **選択から作成** を押す。 ノード名が空なら `<ベース名>_BS`

### 選ぶ・動かす
- 「ターゲット」のメニューで blendShape を選ぶ。 **選択から** でメッシュの
  ヒストリから探す。 外でノードやターゲットを増減したら **更新**
- 各行のスライダーでウェイトを動かす（undo 可）。 名前の横の `(+2)` は
  インビトウィーンの数
- 絞り込み欄に文字を入れて Enter で表示を絞れる（`L_ brow` のように空白区切りで OR）
- **選択メッシュをターゲットに追加** / **チェックしたものを削除**
- **チェック → 0 / 1**、**表示中を全部 → 0**（コントローラーにつながっている
  スライダーは変えない）

### 名前を変える
- 1 つだけチェックして **新しい名前** を入れ **リネーム**
- 検索・置換・接頭辞・接尾辞を入れて **一括リネーム**（チェックしたもの、
  無ければ表示中の全部）。 `L_smile ↔ R_smile` のような入れ替えもできる

### インビトウィーン
- 中間の形のメッシュを選び、ターゲットを 1 つだけチェックして、重み
  （0〜1 の間）を入れて追加する

### ミラー（反対側を作る）
- 元のターゲットにチェックを入れて **反対側を作成**
  - `L_smile` → `R_smile`、`browUp_L` → `browUp_R`、`eyeBlinkLeft` → `eyeBlinkRight`
  - 左右の決まりに当たらない名前は `<名前>_mirror`
- 対称軸と許容誤差（左右の頂点を位置で対応させる距離）を指定できる
- 反対側が既にあるときは、チェックに従って形を上書きする

### 困ったとき
Script Editor（Python）で次を実行し、出力を開発者に送る（シーンは変更しない）:

```python
import blendshape_manager.scene as s; s.diagnose("face_BS")
```

## 更新

**ドラッグ&ドロップし直しても更新されない**（Maya は同じファイルの 2 回目の
ドロップを無視する）。 次のどちらかで更新する。

- ツールウィンドウ下端の **「GitHub から更新」** ボタン
- シェルフボタンを**右クリック** > **Update All Tools from GitHub**

どちらも Maya の再起動は不要。 更新後はウィンドウが自動で開き直り、下端の
バージョン表示が新しい番号に変わる。 **変わっていなければ更新は届いていない。**

## 制約・既知の問題

- **実機未確認**（v0.1.0）
- 1 つの blendShape に複数のメッシュをぶら下げた構成は、1 本目のメッシュだけを扱う
- ミラーは**ベースが左右対称**であることが前提（位置で左右の頂点を対応させる）。
  対応の取れない頂点は動かさず、その数を知らせる
- ミラーで既存のターゲットを上書きしても、そのインビトウィーンは作り直さない
- 更新には GitHub への HTTPS 接続が必要。 塞がれている場合は
  **ルートの README「GitHub に接続できないとき」**のオフライン手順で入れられる
