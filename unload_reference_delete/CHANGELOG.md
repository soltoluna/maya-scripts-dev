# Unload Reference Delete — 変更履歴

現時点の仕様と確定した設計判断は `SPEC.md` を参照。 ここではバージョンごとの
経緯・試行錯誤・不具合修正の細部を記録する。 降順（新しい順）。

## 0.2.0 — 配布をリポジトリ直下のハブに集約
- ツール固有の `install.py` を削除した。 配布と更新はリポジトリ直下の
  `install.py` 1 本が担い、GitHub の tree API で全ツールを自動列挙する。
- このツール側の変更は `SHELF_LABEL = "UnldRefDel"` の追加のみ。
  ハブがシェルフボタンを貼るときに読む。
- 機能面の変更は無し。 **実機未確認**（新しい配布経路そのものも未確認）。

## 0.1.0 — 標準セットに載せた初版
- 既存スクリプト `UnloadReferenceDelete/unloadReferenceDelete.py` を
  `unload_reference_delete` パッケージに作り直した。 フォルダ名の変更は
  CLAUDE.md のモジュール命名規則（snake_case）に合わせたもの。
- 元は import した瞬間に全削除が走る 10 行のスクリプトだった。
  `cmds.file(removeReference=True)` が undo できないことを踏まえ、
  **一覧 → 確認ダイアログ → 削除** の形に変えた。
- 削除の指定をファイルパスからリファレンスノードへ変更。 同じファイルを
  複数回参照していると、パスに `{1}` が付いて指定が曖昧になるため。
- 入れ子のリファレンスを仕分けるようにした（親が削除対象なら子は触らない）。
  親を消すと子も消えるので、そのまま呼ぶと「既に無いノード」でエラーになる。
- 1 件失敗しても残りを続行し、最後にまとめて報告する形にした。
  元は最初の例外でその場で止まっていた。
- **実機未確認。** ここまでの検証はすべて Maya スタブ上のテスト。
