# Unload Reference Delete

## 概要
- バージョン: 0.2.0 / 対応Maya: 2024+
- シーンに残っている**アンロード中（unloaded）のリファレンス**を一覧し、
  まとめて削除する。 Reference Editor に使わない参照が溜まったときの掃除用。

## インストール

1. GitHub の**リポジトリ直下**の `install.py` を開き、**Raw** から保存する
2. 保存した `install.py` を **Maya のビューポートにドラッグ&ドロップ**する
3. 完了ダイアログが出て、シェルフに `UnldRefDel` ボタンが追加される

Maya の再起動は不要。 **この `install.py` はリポジトリの全ツール共通**で、
1 回のドラッグで入っているツールが全部インストール／更新される。

## 使い方

1. シェルフボタンを**左クリック**してウィンドウを開く
2. 一覧でシーン中のリファレンスを確認する。 行頭の印が状態を表す

   | 印 | 意味 |
   |---|---|
   | `x` | **削除対象**（アンロード中） |
   | `-` | アンロード中だが個別には消さない（親ごと消える／ノードが引けない） |
   | （空白） | ロード済み。 触らない |

3. **Delete Unloaded References** を押す。 確認ダイアログに消す対象が並ぶので、
   内容を見て `Delete` を選ぶ
4. 結果（削除できた件数・失敗した件数）がダイアログと Script Editor に出る

**削除は undo できません。** 確認ダイアログは既定で ON にしてあります。
オフにするチェックボックスがありますが、外すと押した瞬間に消えます。

UI を出さずに実行することもできる（元のスクリプトと同じ使い方）:

```python
import unload_reference_delete
unload_reference_delete.remove_unloaded()            # 確認あり
unload_reference_delete.remove_unloaded(confirm=False)  # 確認なし
```

## 更新

**ドラッグ&ドロップし直しても更新されない**（Maya は同じファイルの 2 回目の
ドロップを無視する）。 次のどちらかで更新する。

- ツールウィンドウ下端の **「GitHub から更新」** ボタン
- シェルフボタンを**右クリック** > **Update All Tools from GitHub**

どちらも Maya の再起動は不要。 更新後はウィンドウが自動で開き直り、下端の
バージョン表示が新しい番号に変わる。 **変わっていなければ更新は届いていない。**

どちらの導線も**入っているツールを全部まとめて更新する**（更新の入口が
リポジトリ直下の `install.py` 1 本に集約されているため）。

## 制約・既知の問題

- **削除は undo できない。** `cmds.file(removeReference=True)` は Maya の undo
  キューに乗らない。 元に戻したい場合はシーンを開き直すしかない
- 一覧は開いた時点のスナップショット。 Reference Editor 側で状態を変えたら
  **Refresh** を押す
- リファレンスノードが引けない参照（壊れた参照など）は削除できない。
  一覧には `ノード不明・削除不可` と出る
- **v0.2.0 は実機（会社の Maya）で未確認**。 手元にある検証はスタブによる
  テストのみで、実 Maya でのリファレンス操作は確かめられていない
- 更新には GitHub への HTTPS 接続が必要。 社内プロキシやセキュリティソフトで
  塞がれている場合は Script Editor に `URLError` が出る。 その場合は
  **ルートの README「GitHub に接続できないとき」**のオフライン手順で入れられる
- Maya 2024 / 2025 の両方で動くよう、Python 3.10 の構文と `maya.cmds` だけで
  書いてある
