# Color Override

## 概要
- バージョン: 1.0.0 / 対応Maya: 2024+
- 選択したオブジェクトを任意の色でフラットに塗り分け、**同じような色の
  オブジェクトの貫通（めり込み）をビューポートで見分けられるようにする**。
  元のマテリアル割り当ては記録してあるので、いつでも戻せる。

**v1.0.0 から、マテリアルの割り当てを書き換えずに色を掛ける。**
レンダーセットアップのマテリアルオーバーライドを使うので、**フェース単位で
マテリアルが分かれたモデルでも壊さない**（戻すとそのまま元に戻る）。

陰影の乗らないフラットな色（`surfaceShader`）で塗るので、同系色のオブジェクトが
重なっていても境界が輪郭としてはっきり出る。

## インストール

1. GitHub の**リポジトリ直下**の `install.py` を開き、**Raw** から保存する
2. 保存した `install.py` を **Maya のビューポートにドラッグ&ドロップ**する
3. 完了ダイアログが出て、シェルフに `ColorOvr` ボタンが追加される

Maya の再起動は不要。 **この `install.py` はリポジトリの全ツール共通**で、
1 回のドラッグで入っているツールが全部インストール／更新される。

## 使い方

シェルフボタンを**左クリック**するとウィンドウが開く。

### 任意の色を掛ける

1. **Color** のスライダで色を選ぶ（`Hex` 欄に `#RRGGBB` を直接入れてもよい）
2. オブジェクトを選択する
3. **Apply to Selected**

既に色を掛けてあるオブジェクトに掛け直すと、**色だけが差し替わる**。
元のマテリアルの記録は保たれるので、何度掛け直しても Restore で戻せる。

**グループノードを選んでもよい。** 中のメッシュがまとめて 1 色になり、
Restore すると**それぞれ元のマテリアルに戻る**（中身のマテリアルが
ばらばらでも構わない）。

### セットとして扱われる

**1 回の Apply がひとつの「セット」になる。** 200 個のメッシュにまとめて色を
振っても、一覧は 1 行のまま。

- 名前は `Set 1` のように自動で付く。 **一覧の名前欄を書き換えて Enter**
  でリネームできる
- 一覧には**色見本**が出る（16 進コードは見本にマウスを乗せると出る）
- 行の右側で、そのセットだけ `Hide`／`Show`、`Sel`（シーンで選択）、
  `Restore`（片付ける）ができる

### まとめて塗り分ける

- **Random → Selected** — 選択物に、互いに見分けやすい色を自動で振る
- **Random → All Meshes** — シーンの全メッシュに同上
  （50 個を超えると一度確認が出る）

色は乱数ではなく決まった順序で振られるので、掛け直しても色が入れ替わらない。

### 一瞬だけ元のマテリアルを見る

**Hide Colors** を押すと色が外れて元のマテリアルが見える。 もう一度押す
（**Show Colors** に変わっている）と、同じ色が戻る。

`Restore` と違ってシェーダーは消さないので、**何度でも往復できる**。
色を振り直す必要は無い。

往復を多用するならホットキーに割り当てると速い
（Windows > Settings/Preferences > Hotkey Editor で Runtime Command を作り、
Python で次を実行する）:

```python
import color_override
color_override.toggle()
```

**ウィンドウを開いていなくても動く。**

### 片付けても後から戻せる

`Restore` はシーンからノードごと消すので、**シーンがきれいになる**。 その代わり
片付ける直前に、色分けの控えをシーンの隣へ書き出す。

```
<シーンと同じフォルダ>/<シーン名>.color_override.json
```

片付けたセットは**上の一覧から消え、その下の「控え」欄に移る**。
**`復元` を押せばいつでも同じ色分けが戻り、上の一覧に戻ってくる。**
要らなくなったら名前欄を右クリック > 「控えから削除」。

```
  Sets: 1 applied / 0 backup     ← 掛かっているセット（上の一覧）
  ┌───────────────────────────┐
  │ ■■  hair      12 obj   Hide  Sel  Restore │
  └───────────────────────────┘
  ▼ 控え — 2 セット               ← 片付けたセット（下の欄）
  ┌───────────────────────────┐
  │ shot010.color_override.json  [読み込む…] [既定] │
  │ ■■  body      34 obj        Sel  復元    │
  │ ■   check     3 obj         Sel  復元    │
  └───────────────────────────┘
```

- 欄の左上に**いま読んでいる控えのファイル名**が出る
- **`読み込む…` で別の控えを開ける。** 前のシーンの控え（別名保存で置いてきた
  もの）や、共有フォルダに置いた控えもここから読める。 選んだ控えは
  シーンの隣より優先され、`既定` を押すと元に戻る
- 控えが 0 件でも欄は出る（そこから `読み込む…` で探せるように）
- シーンが未保存のときは、控えの保存先を尋ねる。 **選んだ場所は覚えているので、
  次に開いたときも同じ控えが「控え」欄に出る**
- **控えが書けなかった場合、片付けは実行されない**（消してから
  「書けませんでした」では遅いため）
- 控えの場所はウィンドウ下の「控えの場所を開く」で確認できる

### 元に戻す（記録ごと片付ける）

ウィンドウ中段の一覧には、**いま掛かっているセットだけ**が並ぶ
（片付けたものは下の「控え」欄へ移る）。

- 行の `Sel` を押すと、シーン側でそのセットのオブジェクトが選択される
- **Restore Selected** — 一覧で選んだ行（選んでいなければシーンで選択中のもの）を戻す
- **Restore All** — シーン内のオーバーライドを全部戻す
- **Refresh** — 一覧をシーンの実態から作り直す

一時解除中の行には `(off)` が付く。

掛ける／戻すはどちらも **1 回の Undo（Ctrl+Z）で元に戻る**。

### シーンを保存しても戻せる

元のマテリアル割り当ては、オーバーライド用シェーダーの属性としてシーンに
書き込んである。 **色を掛けたままシーンを保存して開き直しても、Restore は効く。**

ただし、その状態のシーンをそのままレンダリングに回さないこと。 色が乗ったままになる。

## 更新

**ドラッグ&ドロップし直しても更新されない**（Maya は同じファイルの 2 回目の
ドロップを無視する）。 次のどちらかで更新する。

- ツールウィンドウ下端の **「GitHub から更新」** ボタン
- シェルフボタンを**右クリック** > **Update All Tools from GitHub**

どちらも Maya の再起動は不要。 更新後はウィンドウが自動で開き直り、下端の
バージョン表示が新しい番号に変わる。 **変わっていなければ更新は届いていない。**

## うまく動かないとき

**色が乗らない / 戻らないときは、対象を選んで次を実行し、出力をそのまま
貼ってください。**

```python
import color_override
color_override.diagnose()
```

シェイプごとに、シェーダー割り当ての接続（`listConnections`）とフェースの塊
（`objectGrpCompList`）の**生の戻り値**が出ます。 途中で失敗しても
`<ERROR ...>` と値にして続けるので、必ず最後まで出ます。

**レンダーセットアップ方式（v1.0.0 予定）の下調べ**はこちら。 既定では
シーンを一切変更しません。

```python
color_override.probe_render_setup()              # 調べるだけ（安全）
color_override.probe_render_setup(try_it=True)   # 実際に掛けてみる
color_override.probe_render_setup(cleanup=True)  # 試した分を片付ける
```

Apply したときの完了ログも手掛かりになります。

```
[color_override] apply color: 3 object(s) -> Set 1     ← 3 個に掛かった
[color_override] apply color: 0 object(s) -> Set 1     ← 1 個も掛かっていない
```

## 掛け方を切り替える

ウィンドウ上部の **「掛け方」** で選ぶ。

- **レンダーレイヤー**（既定）— レンダーセットアップのマテリアル
  オーバーライド。 **元の割り当てを触らない**ので、フェース単位で分かれた
  モデルでも壊れない。 シーンに `ntk_color_override` レイヤーができ、
  `Restore` で消える
- **シェーダー差し替え** — v0.9.2 までの方式。 割り当てを直接書き換えるので
  **フェース単位の割り当ては失われる**。 レンダーセットアップが使えない
  環境のための逃げ道

切り替えても、**すでに掛かっているものはそのまま**（掛けたときの方式で戻る）。

## 制約・既知の問題

- **v0.4.0 以降はすべて実機未確認。** 開発機に Maya が無いので、テストで確かめられるのは
  純ロジックまで
- 控えはシーンの隣に置くので、**シーンを別名保存すると前の控えは付いてこない**
  （前のシーン名の JSON にそのまま残る）
- **確認済みは Maya 2024 のみ。 2025 は未確認**（色を掛ける／戻す／一時解除の
  いずれも）。 開発機に Maya が無いので、2025 は会社で確かめるまで分からない
- **v0.2.0 以前に色を掛けたまま保存したシーンは、グループに掛けた分の
  戻し先が失われている。** v0.3.0 に更新しても記録は直せないので、
  そのシーンは Restore せずに開き直すこと
- **ホットキーからの `toggle()` は未確認。** UI のトグルボタンは 2024 で確認済み
- ロックされたノードはシェーダー割り当ての編集が禁止されている場合があり、
  そのときはエラーになる可能性がある（リファレンスされたモデルへの割り当ては
  2024 で確認済み）
- フェース単位でマテリアルが分かれているオブジェクトも、メッシュ全体に 1 色が
  掛かる（フェースごとに色を分けることはできない）。 **v1.0.0 の
  「レンダーレイヤー」方式なら元の割り当てを一切触らないので、戻せば
  そのまま元どおり**
  - 「シェーダー差し替え」方式に切り替えた場合は、**フェース単位の割り当てが
    失われる**（v0.9.2 までと同じ）
  - **v0.9.2 以前に掛けたままのオーバーライドは旧方式のもの。** そのシーンは
    Restore せずに開き直して、v1.0.0 で掛け直すこと
  - **v0.4.0 以前に色を掛けたまま保存したシーン**には控えが無いので、
    そのメッシュは従来どおり 1 つのマテリアルに寄る
- 色は `surfaceShader`（陰影なし）固定。 形が見えにくい場合は
  ビューポートの **Shading > X-Ray** や SSAO と併用する
- 更新には GitHub への HTTPS 接続が必要。 社内プロキシやセキュリティソフトで
  塞がれている場合は Script Editor に `URLError` が出る。 その場合は
  **ルートの README「GitHub に接続できないとき」**のオフライン手順で入れられる
- Maya 2024 / 2025 の両方で動くよう、Python 3.10 の構文と `maya.cmds` だけで
  書いてある（PySide は 2024=PySide2 / 2025=PySide6 で互換が無いため使っていない）
