今回のセッションで行った作業を要点のみで docs/PROGRESS.md の一番上(既存エントリの前)に追記してください。

フォーマット:
## YYYY-MM-DD
- やったこと: (3〜5行程度)
- 現状: (どこまで実装したか / テストと check_tools の結果 / **実機確認の状態**)
- 次回: (次にやること)
- メモ: (重要な判断理由やハマった点があれば。なければ省略可)

ルール:
- 会話の詳細やコードの中身は書かないこと。次回セッションが迷わず再開できるための最小限の情報のみ。
- **「現状」には実機(会社の Maya)で確認済みか未確認かを必ず書く。** この開発機に Maya は
  無いので、テストが通っただけの版を「動いた」と書かない。どの版がどこまで確認済みかを
  追えるようにする。
- docs/PROGRESS.md のエントリが10件を超えていたら、古いものを docs/archive/YYYY-MM.md (対象月ごと)に移動してから追記すること。archiveディレクトリが無ければ作成する。
- 追記が終わったら、意味のある単位で git commit し、GitHubにpushすること。
  **push していないものは実機に届かない**ので、ここを省略しない。
- コミットメッセージは "docs: update progress log (YYYY-MM-DD)" のように簡潔にすること。
